# Подготовка Prompt Bank к рассмотрению Pinterest

## Что реализовано

- Проверка HMAC Telegram Mini App (`x-telegram-init-data`) и Login Widget (`x-telegram-login`).
  Один `x-telegram-id` больше не даёт доступ. Подписанные данные действуют не более 24 часов.
- Общий аккаунт публикации проекта, доступный только администраторам из `ADMIN_TELEGRAM_IDS`.
  Это не сервис подключения произвольных аккаунтов посетителей.
- Настройки → Pinterest → официальный OAuth → возврат в настройки.
- Одноразовый `state`, привязка к HttpOnly cookie браузера, срок 10 минут.
  Состояние хранится в PostgreSQL, поэтому не теряется при рестарте сервера.
- Токены доступа и обновления шифруются AES-256-GCM, обновляются при истечении срока.
  Браузер получает только статус подключения и выбранную доску.
- Выбор доски через Pinterest API, подтверждение доски и Telegram-поста перед каждым пином.
- Отключение удаляет токены и отменяет незавершённые подключения. Старый токен из переменных
  окружения не включается обратно после отключения. Уже созданные пины не удаляются.
- Политика конфиденциальности описывает интеграцию и способ отключения.

## Конфигурация backend

```env
PINTEREST_CLIENT_ID=<App ID из Pinterest Developers>
PINTEREST_CLIENT_SECRET=<App secret>
PINTEREST_REDIRECT_URI=https://prompt-bank.one/api/pinterest/callback
PINTEREST_TOKEN_ENCRYPTION_KEY=<64 случайных hex-символа>
WEBAPP_URL=https://prompt-bank.one
PUBLIC_SITE_URL=https://prompt-bank.one
BOT_TOKEN=<токен бота входа Telegram>
ADMIN_TELEGRAM_IDS=<Telegram ID администратора>
```

`PINTEREST_REDIRECT_URI` должен символ в символ совпадать с разрешённым Redirect URI
в кабинете Pinterest. Указанный адрес подходит для текущей схемы, где `prompt-bank.one`
обслуживает Express API и проксирует miniapp. Не копируйте старый адрес из прежних инструкций
без проверки маршрутизации домена.

Если зарегистрированный callback использует другой домен backend (например Railway URL),
он также поддерживается: приложение сначала открывает `/api/pinterest/authorize` на домене
callback, устанавливает там проверочный cookie и только затем перенаправляет на Pinterest.
Этот домен должен обслуживаться тем же backend; frontend-домен без Express API не подходит.

Запрашиваются только `boards:read,pins:write`; создание досок и чтение пинов приложению не нужны.
Создайте доску заранее в Pinterest. Подключение для записи видео выполняйте в обычном браузере.

Сгенерировать ключ локально:

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

Сохраните результат в секретной переменной backend Railway, не в Git, скриншоте или видео.
Ключ нужно сохранять при перезапусках: его смена делает старые токены нерасшифровываемыми;
в таком случае отключите интеграцию и подключите аккаунт заново. Копии базы следует защищать
и удалять по принятому сроку хранения — отключение интеграции не переписывает старые бэкапы.

`PINTEREST_ACCESS_TOKEN` и `PINTEREST_BOARD_ID` поддерживаются только для перехода со старой
установки, пока в базе вообще нет записи подключения. После успешного OAuth удалите старые
переменные из Railway. Не используйте их для демонстрации подключения.

## Миграция и развёртывание

Перед обновлением создайте резервную копию production PostgreSQL. Исторические Prisma migrations
в проекте относятся к SQLite: не запускайте `prisma migrate deploy` или `migrate reset`.

Аддитивный SQL добавляет только `PinterestConnection` и `PinterestOAuthState`:

```powershell
cd D:\prompt-bank-main\repository\backend
npm run prisma:patch-pinterest
```

Команда использует базу из окружения процесса; сначала убедитесь, что выбран нужный экземпляр.
Для запуска через Railway CLI используйте окружение backend с доступным PostgreSQL URL, а не
выводите DATABASE_URL в терминал. При обычном старте backend существующая команда
`prisma db push --skip-generate` также добавляет новые таблицы. Если она сообщает о потере
данных, остановитесь и разберите расхождение схемы; не добавляйте `--accept-data-loss`.

Проверки до push (push в main автоматически разворачивает оба сервиса):

```powershell
cd D:\prompt-bank-main\repository\backend
npm run test:security
npm run test:publications
npm run test:titles
npm run test:media
npm run build
cd ..\miniapp
npm run build
```

Обновите backend и miniapp вместе: старый клиент отправляет неподписанный ID и больше не сможет
выполнять действия с аккаунтом. После обновления нужно заново войти через Telegram; в Mini App
при истечении 24 часов закройте и откройте приложение. Для Login Widget домен сайта должен быть
разрешён у бота через BotFather `/setdomain`.

## Ручная проверка перед записью

1. Войти через Telegram под администратором. Проверить, что у обычного посетителя нет блока Pinterest.
2. Настройки → Подключить Pinterest → разрешить доступ на официальной странице → возврат «Подключён».
   Не показывать переменные Railway, токены, секреты или приватные уведомления на записи.
3. Выбрать доску. Проверить отключение и повторное подключение без вывода токенов.
4. Проверить доступность `https://prompt-bank.one/privacy` без входа и указать её в заявке.
5. Подготовить один материал с правами на изображение и ссылкой на существующий публичный
   Telegram-пост с соответствующим промптом. Старый пост повторно в канал не отправлять.
6. С отдельным разрешением владельца выполнить одну живую Pinterest-публикацию. Проверить
   название, описание, доску, изображение, «Открыть Pin» и переход на нужный пост Telegram.
   До этой проверки нельзя считать живую интеграцию подтверждённой.

## Видео для заявки

Рекомендуемый короткий сценарий (продолжительность не является требованием Pinterest):

1. Показать сайт и объяснить: Prompt Bank помогает администратору публиковать собственные
   изображения с промптами; назначение пина — соответствующий пост Telegram.
2. Показать полный официальный OAuth-переход из настроек приложения и возврат со статусом подключения.
   Самостоятельно вводить пароль Pinterest, если он запрашивается; убрать пароль из записи.
3. Выбрать доску, открыть подготовленный материал, показать итоговые поля и ссылку.
4. Явно подтвердить один пин, дождаться успешного ответа.
5. «Открыть Pin» → показать пин на Pinterest → перейти по ссылке на конкретный Telegram-пост.
6. При необходимости показать кнопку отключения и публичную политику конфиденциальности.

В Trial пины могут быть видны только создателю; демонстрируйте их под тем же аккаунтом.
Проверьте фактический Trial-статус и доступность Upgrade в кабинете, заполните честное описание
инструмента для администратора собственного аккаунта, загрузите видео и отправьте на Standard review.
Одних мокапов и обзора дизайна недостаточно; одобрение не гарантируется.
